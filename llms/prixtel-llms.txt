# Prixtel

> Prixtel is a French mobile virtual network operator (MVNO) founded in 2004 by David
> Charles in Aix-en-Provence, best known for "forfaits flexibles" — mobile plans whose
> monthly price moves automatically between published tiers according to the data the
> subscriber actually consumed, with the ceiling known in advance. It rides the SFR
> (and historically Orange) radio network rather than owning spectrum, serves roughly
> 300,000–500,000 subscribers, and was acquired by Altice France in June 2021 for about
> €415 million while continuing to trade under its own brand. Prixtel publishes **no
> public API, no developer portal, and no machine-readable contract of any kind**; its
> only first-party software surface is an end-user iOS/Android app.

## What an agent can and cannot do here

- There is **nothing to call.** No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, webhook
  catalog, MCP server, or A2A agent card exists on any Prixtel host.
- `api.prixtel.com` resolves and is a live nginx origin — it is the private backend for
  the Prixtel mobile app — but it returns HTTP 404 on its root and on every probed path.
  It is not a documented, credentialed, or supported integration surface. Do not treat it
  as one.
- `robots.txt` disallows `/ws-externe/`, the only path on the estate whose name implies a
  machine interface. It was not probed and is not documented. Honor the disallow.
- Everything an agent can usefully read about Prixtel is retail: tariffs, coverage,
  contract terms, and support articles, all in French, all human-readable HTML.
